# tools/sweep

`pnpm sweep <command>`: the deterministic steps of the consistency sweep.
Design: `docs/superpowers/specs/2026-09-30-sweep-design.md`; decisions:
`docs/decisions/2026-09-30-sweep-decisions.md`. The owner-facing entry is the
`sweep` skill (`.claude/skills/sweep/`), whose lead runs these commands.

| Command                                                                                               | What it does                                                                                                                                                                                                                                                                                                                                                                             |
| ----------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pnpm sweep lint`                                                                                     | Relative links resolve; live specs, plans and research name their beads; no agent instructions or hooks name graphify                                                                                                                                                                                                                                                                    |
| `pnpm sweep match <findings.json> --run <dir>`                                                        | Gives the checkers' findings `SW-` IDs and fingerprints, matches each against open sweep beads and earlier findings of the run (filed) and the ledger (regression, pending, suppressed, candidate, related, new), and spends the IDs in `sweep/last-run`                                                                                                                                 |
| `pnpm sweep ledger add <line.json>`                                                                   | Appends one checked line; refuses a reused ID or an event for an unknown one                                                                                                                                                                                                                                                                                                             |
| `pnpm sweep snapshot --run <dir>`                                                                     | Every open bead, every closed `decision` bead and every memory as linked Markdown in `<dir>/snapshot/`, with `index.json` mapping each file to the ref findings cite (`bead:<id>`, `memory:<key>`). One `bd export`: about two seconds                                                                                                                                                   |
| `pnpm sweep timeline --side '<json>'`                                                                 | A side's origin: written and last-changed dates (`git blame -M -C` on its lines, or the file's history; both follow moves), the latest commit, its PR and subject, and whether the owner approved the text, with the evidence                                                                                                                                                            |
| `pnpm sweep archive --candidates [--json]`                                                            | Which specs, plans and research are done: every bead the header names (and a plan's spec's) closed with all its children. A group stays live while something cites it as a design: a `CLAUDE.md` or skill naming its path or area (\"backend spec §10.3\"), or the header of a live spec, plan or research file. A file naming no bead known to bd is unlinked, with its citations shown |
| `pnpm sweep archive <path>...`                                                                        | Refuses a cited file. `git mv` into `docs/archive/` at the same path, drops the files from `unlinked.json`, rewrites every relative link, and every mention of a moved path in code, config and live docs (never in fenced code, decision logs, reviews or the archive); fails if an old path or a broken link is left                                                                   |
| `pnpm sweep graph --run <dir>`                                                                        | Stages the live docs and code (Markdown, TS/JS, Python; no config, no `.claude/` settings) and the run's snapshot in `.superpowers/sweep/cache/stage/`, runs `graphify extract … --backend claude-cli` from a neutral temp folder (so no repo `CLAUDE.md` or hooks load), reuses the graph while the commit and snapshot are unchanged, and writes `<dir>/topics.json`                   |
| `pnpm sweep rank --run <dir>`                                                                         | Orders the root causes in `<dir>/to-file.json` (the findings the lead routed on, in `match`'s shape): user-visible first, then open beads that name the area, then graph reach                                                                                                                                                                                                           |
| `pnpm sweep verify <batch> [--skip-check]`                                                            | After a batch is applied: every losing quote gone from every live file, open bead and memory (kept on purpose is fine: ledger, archive, reviews, executed plans, decision and design-spec entries marked superseded, decision beads superseded in part; a pending code side is skipped), each winner at its home (read from bd or disk if not live), links resolve, `pnpm check` green   |
| `pnpm sweep recall plant --out <dir>` / `recall snapshot --run <dir>` / `recall score <matched.json>` | Plants the seeds of `src/seeds/seeds.json` in a committed clone (and bead or memory seeds in a run's snapshot, never in bd), and scores a run's findings against them                                                                                                                                                                                                                    |
| `pnpm sweep state get` / `state set <state.json>`                                                     | The baseline in `bd kv` under `sweep/last-run`                                                                                                                                                                                                                                                                                                                                           |

## Rules

- **Node runs the source directly**: relative imports end in `.ts`, and only
  erasable TypeScript syntax is allowed.
- **Graphify serves only the sweep** (decision S1, narrowing H7). Nothing but
  this package's graph step calls it, headless; never run `graphify install`,
  `graphify claude install`, or install its git hooks. Pinned version:
  **0.9.72** (`GRAPHIFY_VERSION` in `src/graph.ts`), installed with
  `uv tool install graphifyy==0.9.72`; move it only to a release at least a
  day old. `extract --backend claude-cli` calls `claude -p`, billed to the
  owner's Claude plan; `GRAPHIFY_CLAUDE_CLI_MODEL` picks the model (the graph
  step defaults it to `sonnet`). Calls are small (`TOKEN_BUDGET`, about 17
  beads each) and run four at a time: Graphify's 60k default times out on
  the bead snapshot and bisects for hours. The lint fails if any
  `CLAUDE.md`, settings file or hook outside this package and the sweep skill
  names it.
- **Fingerprints are anchors, never wording.** A finding's fingerprint is
  the hash of its stable IDs and side refs (with the bead field), archived
  paths mapped back to `docs/`. Matching recomputes it for every ledger line,
  so changing `anchors` never orphans settled items; two findings on the same
  places are one item only if their quotes overlap.
- **Tests build throwaway git repos** (`src/testing.ts`); nothing calls
  Graphify or a model.
