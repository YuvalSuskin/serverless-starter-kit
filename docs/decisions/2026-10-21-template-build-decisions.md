**Date:** 2026-10-21
**Owner:** Yuval Suskin
**Beads:** the template tracker's epic `acme-8fr` (the harness gaps); this log itself has no bead

The interchangeable choices made while turning the first project into this
template: another choice would serve as well, so the implementer made it,
recorded it here, and carried on (the owner's rule,
`docs/superpowers/plans/CLAUDE.md`). Add one row per decision, in order, with
the next number. Never renumber. If a later decision replaces one, add a new
row and mark the old one *Superseded by TB<n>*.
